PROYECTO 3 - CARTERA PERSONAL
Sitio web multipágina de One Piece (HTML y CSS)

ARCHIVOS
- index.html: página de inicio.
- proyectos.html: tripulación.
- articulos.html: artículos.
- contacto.html: formulario de contacto.
- style.css: estilos compartidos para todas las páginas.

REQUISITOS INCLUIDOS
- Diseño adaptable a móviles y computadores.
- Paleta de colores y tipografía consistentes.
- Google Fonts (Poppins).
- Flexbox, media queries y box-sizing: border-box.
- Navegación adaptable con menú hamburguesa en pantallas pequeñas.
- Formulario de contacto estilizado.
- Modo oscuro mediante variables CSS.
- Comentarios en el CSS para explicar las secciones principales.

PARA PROBAR
1. Extrae la carpeta.
2. Abre index.html en el navegador.
3. Usa el menú para navegar por las cuatro páginas.
4. En la parte superior, activa “Modo oscuro”.
5. Reduce el ancho de la ventana para probar el diseño móvil.

PUBLICAR GRATIS CON GITHUB PAGES
1. Sube estos archivos a un repositorio de GitHub.
2. En el repositorio entra a Settings > Pages.
3. En “Build and deployment”, elige “Deploy from a branch”.
4. Selecciona la rama principal (por ejemplo, main) y la carpeta /(root).
5. Guarda y espera a que GitHub genere el enlace.

NOTAS
- La fuente de Google Fonts requiere conexión a Internet; si no hay conexión se usa Arial.
- El formulario es visual y no envía correos todavía. Para recibir mensajes de verdad hace falta conectarlo a un servicio o servidor.
